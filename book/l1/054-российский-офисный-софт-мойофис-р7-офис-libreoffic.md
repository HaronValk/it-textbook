## 2. Теория «под капотом» (как это работает: архитектура, протоколы)

Офисный стек состоит из трёх слоёв, и путать их — главная причина ошибок в поддержке.

**Слой 1 — приложение (редактор).** Программа, которая рисует документ на экране и умеет его сохранять. Бывает десктопной (LibreOffice, МойОфис, Р7-Офис Десктоп) и веб-офисом в браузере (Яндекс 360 Документы, Р7-Офис Сервер, МойОфис в частном облаке).

**Слой 2 — формат файла.** Два основных семейства:
- **OOXML** — `.docx`, `.xlsx`, `.pptx`. «Родной» для Microsoft Office, поддерживается всеми остальными частично.
- **ODF** (Open Document Format) — `.odt`, `.ods`, `.odp`. Открытый стандарт ISO, родной для LibreOffice.

Оба формата внутри — это **ZIP-архив с XML-файлами**. Не веришь — скопируй `sverka.docx` в `sverka.zip` и распакуй: увидишь `word/document.xml`, папку `word/media` с картинками и т.д. Отсюда важное следствие: файл это не «картинка», а описание «что и где нарисовать». Каждая программа рисует это описание по-своему.

**Слой 3 — среда.** Локальный диск, сетевая папка (`\\FS01\Obshchee`, SMB-порт 445), облако (HTTPS 443) или почта (IMAP 993, SMTP 465/587).

```
[Рабочее место WIN11-CL01]
   приложение: МойОфис / Р7-Офис / LibreOffice / Word
        |  открывает -> парсит ZIP+XML -> рисует на экране
        v
   ФАЙЛ sverka.docx
        |
        +--> локальный диск C:\Users\ivanov\Documents
        +--> SMB  \\FS01\Buh        (порт 445)
        +--> печать: спулер -> FS01 (порт 445/9100)
```

```
[Браузер] --HTTPS 443--> [Яндекс 360 / VK WorkSpace / МойОфис Cloud]
   |                          |
   |  совместное редактирование (WebSocket поверх 443)
   |                          |
   +-- почтовый клиент:  IMAP 993 (входящая), SMTP 465/587 (исходящая)
```

**Почему «поехало».** Причины стабильные и повторяемые:
1. **Шрифты.** Если в документе Times New Roman, а в системе его нет, программа подставит замену с другими метриками (шириной букв) — текст перестанет влезать в строки, таблицы разъедутся. Решение — метрически совместимые шрифты (Liberation Serif ↔ Times New Roman, Liberation Sans ↔ Arial, Carlito ↔ Calibri, Caladea ↔ Cambria).
2. **Неполная поддержка функций.** Сводные таблицы, сложные диаграммы, VBA-макросы, элементы ActiveX, некоторые виды условного форматирования поддерживаются частично или не поддерживаются вовсе.
3. **Разная вёрстка.** Даже при одинаковых шрифтах алгоритмы переноса строк и расчёта отступов отличаются.

**Лицензирование** — то, что L1 обязан понимать, потому что половина «оно не работает» на самом деле «истекла лицензия». LibreOffice — свободное ПО (лицензия MPL 2.0), бесплатен и в РФ, и где угодно. МойОфис и Р7-Офис — коммерческие продукты из реестра российского ПО, продаются по подписке или бессрочно, обычно «на пользователя» или «на устройство» (точные редакции и цены — `[ПРОВЕРИТЬ]` на сайтах вендоров). Яндекс 360 для бизнеса и VK WorkSpace — подписочные облачные сервисы, у обоих бывают бесплатные/пробные тарифы для маленьких команд `[ПРОВЕРИТЬ актуальные условия]`.

## 3. Аналогия из жизни

Документ — это **нотная партитура**. Приложение — **оркестр**, который её исполняет. Пока партитуру играет тот оркестр, для которого её писали (Word), всё звучит ровно так, как задумал автор. Отдаём ту же партитуру другому оркестру (LibreOffice, МойОфис) — музыканты сыграют ту же мелодию, но у них другие инструменты: где-то нет тубы (сводной таблицы), где-то скрипка звучит чуть тише (шрифт с другими метриками), и дирижёр расставляет паузы по-своему. Мелодия узнаваема, но запись в программке будет выглядеть иначе.

Облачный офис (Яндекс 360, VK WorkSpace) в этой метафоре — репетиция с дирижёром в реальном времени: все музыканты видят правки друг друга сразу, но только пока есть связь с залом.

Аналогия перестаёт работать в одном месте: музыка каждый раз звучит заново и портиться ей негде, а документ при неаккуратном сохранении **молча запишет ошибку в файл** — и оригинал будет потерян.

## 4. Практика и команды

**1. Поиск и установка LibreOffice на Windows**

```powershell
winget search libreoffice
winget install --id TheDocumentFoundation.LibreOffice -e
```
`search` ищет пакет в репозитории winget, `-e` (exact) требует точного совпадения идентификатора. Если id не находится `[ПРОВЕРИТЬ]`, ставь вручную с libreoffice.org (разрядность x86-64). Ожидаемый вывод — строка `Successfully installed`. Что смотреть: не поставилась ли 32-битная версия и в какой каталог.

**2. Версия на Windows и Linux**

```powershell
& "C:\Program Files\LibreOffice\program\soffice.exe" --version
```
```bash
libreoffice --version
```
Вывод вида `LibreOffice 24.x.x ...` (номер зависит от версии). Смотрим: версия одинаковая на всех машинах парка? Разнобой версий — частая причина «у меня открывается, у неё нет».

**3. Головная конвертация в PDF (Linux/сервер)**

```bash
soffice --headless --convert-to pdf --outdir /tmp/out /tmp/sverka.docx
```
`--headless` — без графического интерфейса, `--convert-to pdf` — целевой формат, `--outdir` — куда положить. Вывод: `convert /tmp/sverka.docx -> /tmp/out/sverka.pdf using filter : writer_pdf_Export`. Смотрим: файл создан, размер не 0 байт, открывается.

**4. Конвертация в docx из другого формата**

```bash
soffice --headless --convert-to "docx:MS Word 2007 XML" --outdir /tmp/out /tmp/sverka.odt
```
Формат после двоеточия — имя фильтра экспорта (для таблиц — `xlsx:Calc MS Excel 2007 XML`). Нужно, когда пользователь сохранил в ODF, а контрагент просит docx.

**5. Сброс профиля LibreOffice (лечит «зависает на заставке»)**

```powershell
Stop-Process -Name soffice* -Force -ErrorAction SilentlyContinue
Rename-Item "$env:APPDATA\LibreOffice\4\user" "user.bak"
```
```bash
mv ~/.config/libreoffice/4/user ~/.config/libreoffice/4/user.bak
```
Профиль — папка с настройками и кэшем; при повреждении LibreOffice может не стартовать. Переименование = сброс к заводским настройкам, старая папка остаётся для отката. Смотрим: появилась ли папка `user` заново после запуска.

**6. Установка и проверка пакетов на Ubuntu**

```bash
sudo apt update
sudo apt install -y libreoffice-writer libreoffice-calc fonts-liberation
dpkg -l | grep libreoffice
```
`-y` — без вопросов, `dpkg -l` показывает установленные пакеты и версии (`ii  libreoffice-writer  1:7.x...`). Смотрим: статус `ii` (установлен), а не `rc` (удалён, конфиги остались).

**7. Проверка шрифтов и метрических замен (Linux)**

```bash
fc-match "Times New Roman"
fc-list | grep -i liberation
```
`fc-match` показывает, какой реальный шрифт подставится вместо запрошенного. Типичный вывод: `LiberationSerif-Regular.ttf: "Liberation Serif" "Regular"` — значит, метрическая замена работает. Если выводится `DejaVu Serif` — вёрстка поедет. Лечится: `sudo apt install fonts-liberation fonts-crosextra-carlito fonts-crosextra-caladea fonts-paratype`.

**8. Что за офисный пакет установлен (Windows)**

```powershell
Get-ItemProperty HKLM:\Software\Microsoft\Windows\CurrentVersion\Uninstall\*,
                 HKLM:\Software\WOW6432Node\Microsoft\Windows\CurrentVersion\Uninstall\* |
  Where-Object { $_.DisplayName -match 'LibreOffice|МойОфис|Р7|Office' } |
  Select-Object DisplayName, DisplayVersion, InstallDate
```
Читаем ветки реестра с списком установленного ПО. Смотрим: название, версию, дату. Два пакета одновременно — нормально, но пользователь должен понимать, каким открывает.

**9. Проверка ассоциации файлов**

```powershell
Get-ItemProperty 'HKCU:\Software\Microsoft\Windows\CurrentVersion\Explorer\FileExts\.docx\UserChoice'
cmd /c assoc .docx
```
`UserChoice` — личный выбор пользователя (перебивает всё), `assoc` — системная привязка расширения. Вывод `ProgId : Word.Document.12` означает Word; `LibreOffice.*` — LibreOffice. Смотрим: что реально откроется по двойному клику. Меняется через «Параметры → Приложения → Приложения по умолчанию».

**10. Настройка формата сохранения (GUI)**

LibreOffice: **Сервис → Параметры → Загрузка/Сохранение → Общие → «Всегда сохранять как»** → выбрать `Word 2007–365 (*.docx)`. Там же галочка «Предупреждать при сохранении не в ODF или формате по умолчанию». МойОфис/Р7-Офис: аналогичный пункт в настройках приложения (путь отличается — `[ПРОВЕРИТЬ]` в справке вендора).

**11. Диагностика почты облачного сервиса**

```powershell
Test-NetConnection imap.yandex.ru -Port 993
Resolve-DnsName -Type MX corp.vektor.lab
```
`Test-NetConnection` проверяет TCP-доступность порта. Вывод: `TcpTestSucceeded : True`. `Resolve-DnsName -Type MX` показывает почтовые записи домена. Смотрим: порт открыт (не режет ли файрвол/провайдер) и куда указывает MX. Параметры серверов и порядок записей для Яндекс 360 и VK WorkSpace — `[ПРОВЕРИТЬ]` в справке сервиса, они меняются.

**12. Зависший процесс офиса / «файл занят другим пользователем»**

```powershell
Get-Process soffice* | Select-Object Id, ProcessName, StartTime
Stop-Process -Name soffice* -Force
```
Часто после «падения» остаётся фоновый процесс, держащий файл. Смотрим: есть ли процесс без окна. В нормальной среде перед `Stop-Process` предупреждаем пользователя о несохранённых данных.

2. **Проверить, чем открывается файл**: `Get-ItemProperty ...FileExts\.xlsx\UserChoice` и список установленных пакетов (п. 4.8). Возможно, часть файлов уже открывается другим офисом — тогда «съехало» не из-за LibreOffice.
3. **Воспроизвести самому** на копии файла, не на оригинале. Копию положить в `\\FS01\Obshchee\L1-054\repro`.
4. **Разобрать `####`**: это не ошибка и не «порча файла», а признак того, что число не влезает в ширину столбца (либо стоит текстовый формат ячейки). Лечение: расширить столбец / изменить формат ячейки. Пользователю объяснить, что данные целы.
5. **Разобрать шрифт**: на машине пользователя проверить наличие Times New Roman (панель «Шрифты» или `fc-match` на Linux). Если шрифта нет легально — поставить метрически совместимые Liberation/PT (в составе LibreOffice или `fonts-liberation`, `fonts-paratype`), а не тащить `ttf` из интернета.
6. **Разобрать формат сохранения**: Сервис → Параметры → Загрузка/Сохранение → Общие → «Всегда сохранять как» = docx/xlsx. Плюс правило для пользователя: **оригинал с шары не перезаписывать**, работать через «Сохранить как» с новой версией.
7. **Проверить печать** после правок — вёрстка могла «поехать» именно на纸. Отправить на принтер FS01.

**Решение:** расширен столбец (или изменён формат ячейки), установлены метрически совместимые шрифты, формат сохранения по умолчанию переключён на docx/xlsx, пользователю выдан короткий регламент «как сохранять, чтобы не потерять оригинал».

**Ответ пользователю:** «Иван, данные в файле целы. `####` — это не поломка: так Excel/LibreOffice показывает число, которое не влезает в ширину столбца, я её расширил. Шрифт заменил на совместимый с Times New Roman, документ теперь по длине совпадает с оригиналом. Формат сохранения по умолчанию переключил на `.xlsx`/`.docx`, так что предупреждение больше не появится. Важно: оригиналы на `\\FS01\Buh` не перезаписываем — сохраняем через «Сохранить как» с новым именем. Проверьте, пожалуйста, и напишите, если что-то ещё не так».

**Закрытие заявки:** категория «Прикладное ПО / офисный пакет», решение — в базу знаний (статья «LibreOffice: шрифты, формат сохранения, ####»), статус «Решено», привязка к заявке.

## 6. Ошибки новичков и безопасность

1. **«Сохранить» вместо «Сохранить как» в чужом формате** → приводит к необратимой потере формул, макросов, сложной вёрстки в оригинале. Правильно: сначала копия, оригинал — только на чтение.
2. **Обещать «стопроцентную совместимость с Word»** → приводит к конфликту с пользователем, когда документ всё-таки поедет. Правильно: честно говорить «открывает и в целом сохраняет, но сложные элементы могут отображаться иначе» и проверять на конкретном файле.
3. **Игнорировать шрифты** → «поехавшие» бланки, договоры и печатные формы. Правильно: ставить метрически совместимые шрифты и обязательно проверять результат на печати/PDF.
4. **Массово менять ассоциации через GPO без пилота** → десятки однотипных заявок за один день. Правильно: пилот на 1–2 машинах в отдельной OU, потом раскатка.
5. **Ставить второй офисный пакет «на всякий случай», не согласовав** → лицензионный хаос, двойные ассоциации, непонятно, чем открывается файл. Правильно: согласование, инвентаризация, единый стандарт.
6. **Не проверять срок лицензии/подписки** → через месяц «внезапно всё заблокировалось» у всего отдела. Правильно: вести реестр лицензий, ставить напоминания заранее.
7. **Тащить шрифты и «кряки» офиса из интернета** → вредоносное ПО и нарушение лицензий. Правильно: официальные дистрибутивы, свободные шрифты, evaluation/триалы.
8. **Путать «не открывается файл» с «не открывается сайт/шара»** → диагностика не туда. Правильно: сначала проверить доступ к ресурсу (SMB/HTTPS), потом приложение, потом формат.

### Безопасность

В боевой среде **нельзя**: отключать защиту от макросов и добавлять папки в «доверенные» целиком; открывать документы из почты без проверки отправителя (макросы — классический вектор атаки); загружать рабочие документы в личные облачные аккаунты (риск утечки, а для персональных данных — нарушение 152-ФЗ); давать общий аккаунт облачного офиса на отдел (нет аудита, невозможно понять, кто что сделал); выдавать ссылки на файлы «всем, у кого есть ссылка» без срока действия и пароля. В учебном стенде мы ставим простые настройки ради удобства — в реальной компании любое такое послабление оформляется заявкой и согласуется с ИБ.

## 7. Вопросы на собеседовании (3–5 вопросов с ответами)

**1. «Чем МойОфис и Р7-Офис отличаются от LibreOffice? Что бы вы выбрали для компании?»**
Ответ: LibreOffice — свободное ПО без стоимости лицензий, но без вендорской поддержки в РФ. МойОфис и Р7-Офис — коммерческие российские продукты из реестра отечественного ПО, с техподдержкой, документацией на русском, интеграцией с отечественными ОС и средствами криптозащиты, но за деньги (подписка или бессрочная лицензия). Выбор зависит от требований: если компания в госсекторе и обязана использовать ПО из реестра — берём МойОфис/Р7; если бюджет ограничен и достаточно базового функционала — LibreOffice. Плюс смотрим на совместимость с уже существующими документами и на наличие поддержки.
*Что хочет услышать интервьюер:* понимание разницы между «бесплатно» и «с поддержкой и в реестре», а не «LibreOffice хуже».
*Красный флаг:* «LibreOffice — пиратская копия Word» или «разницы нет никакой».

**2. «Пользователь говорит, что после перехода на LibreOffice документы "поехали". Ваши действия?»**
Ответ: уточняю, какие именно документы и что значит «поехали»; прошу конкретный файл; воспроизвожу на копии. Проверяю по порядку: шрифты (наличие метрически совместимых), сложные элементы (сводные таблицы, макросы, диаграммы), версию LibreOffice, настройки формата сохранения. Чаще всего причина — шрифты и неполная поддержка функций. Решение: установить совместимые шрифты, для проблемных документов — открывать в том пакете, где они созданы, либо конвертировать в PDF для передачи вовне. Обязательно проверяю печать.
*Что хочет услышать интервьюер:* системный порядок диагностики и понимание, что «поехало» — это не всегда баг.
*Красный флаг:* «Снесу LibreOffice и поставлю Word» без выяснения причин.

**3. «Как сделать, чтобы LibreOffice по умолчанию сохранял в docx?»**
Ответ: Сервис → Параметры → Загрузка/Сохранение → Общие → «Всегда сохранять как» → Word 2007–365 (*.docx). Для таблиц — аналогично `xlsx`. Можно раскатать централизованно через профиль пользователя или GPO/скрипт, но сначала — пилот. Важно предупредить пользователя, что при сохранении в неродной формат часть функций может теряться, а оригиналы лучше не перезаписывать.
*Что хочет услышать интервьюер:* знание конкретного пути в меню и понимание компромисса «удобно, но не без потерь».
*Красный флаг:* «Никак, пусть сохраняют в ODF».

**4. «Пользователь не может подключить рабочую почту Яндекс 360 в Outlook. Что проверяем?»**
Ответ: включён ли доступ по IMAP в настройках ящика; не включена ли двухфакторная аутентификация, требующая пароля приложения; правильные ли сервер и порт (IMAP 993 SSL, SMTP 465/587); не блокирует ли файрвол/антивирус исходящие соединения; проверяю доступность порта `Test-NetConnection`. Если почта на своём домене — проверяю MX-записи и SPF/DKIM (см. урок 53). Точные параметры серверов всегда сверяю в справке сервиса — они могут меняться.
*Что хочет услышать интервьюер:* что вы проверяете настройки на стороне сервиса, а не только «переустановите Outlook».
*Красный флаг:* «Яндекс не поддерживает Outlook».

**5. «Какие риски для компании в том, чтобы просто поставить всем бесплатный LibreOffice?»**
Ответ: отсутствие вендорской поддержки и SLA (проблему решаем сами), возможные сложности с совместимостью критичных документов и с интеграцией с 1С/ЭДО/криптоплагинами, отсутствие продукта в реестре при работе с госструктурами, вопросы к обновлениям и централизованному управлению. Плюс человеческий фактор: людям нужно обучение. Митигация — пилот, тестирование ключевых сценариев, база знаний, при необходимости — гибрид: LibreOffice для большинства, лицензионный пакет для тех, кому нужны специфические функции.
*Что хочет услышать интервьюер:* взгляд «не только цена», учёт требований регуляторики и поддержки.
